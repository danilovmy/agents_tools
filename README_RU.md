# agents_tools

Инструменты для LLM-агентов. [English](README.md)

## OCR-скиллы

В каждом скилле есть инструкции по установке и использованию на русском и английском языках, а также проверка после установки:

- [Xiaomi OCR](skills/ocr-reader-xiaomi/README_RU.md) — локальное распознавание изображений и PDF с помощью Xiaomi-OCR-0. [Проверка](skills/ocr-reader-xiaomi/test/README.md#проверка-установленного-xiaomi-ocr).
- [docTR OCR](skills/ocr-reader/README_RU.md) — распознавание изображений и PDF с помощью docTR и выпрямление изображений через docuwarp. [Проверка](skills/ocr-reader/test/README.md#проверка-установленного-ocr-скилла).

Каждый скилл использует собственное окружение Python и файл `.env`. Интеграция по умолчанию рассчитана на Windows и OpenClaw; для самостоятельного запуска и других агентов используйте `-s`. При первом запуске могут загружаться веса моделей. Реальная работа OCR на Linux и macOS не проверялась.

Скрипты перемещают входные файлы в папку `data/archive` скилла и сохраняют там распознанный текст. Используйте копию, если исходный файл должен остаться на месте. Параметры, настройка моделей, поддержка языков и поведение архива описаны в инструкциях каждого скилла.
