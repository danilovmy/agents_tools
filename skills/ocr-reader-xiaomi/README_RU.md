# Xiaomi OCR reader

[English](README.md)

Локальное распознавание изображений и многостраничных PDF с помощью Xiaomi-OCR-0, Transformers и PyTorch. Изображения не выпрямляются; PDF обрабатываются постранично. Основная интеграция рассчитана на Windows и уведомления OpenClaw. Другие агенты и операционные системы могут отключить уведомления с помощью `-s` при наличии совместимых зависимостей Python. Linux и macOS пока не проверялись.

## Установка

Поместите папку `ocr-reader-xiaomi` целиком, включая файл `.env`, туда, где ваш агент ищет скиллы. Внутри неё создайте окружение Python 3.12 и установите зависимости:

```powershell
python -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

В Linux или macOS используйте `python3.12 -m venv .venv`, а для установки и запуска — `.venv/bin/python`. На целевой системе должны быть доступны совместимые зависимости.

В прилагаемом `.env` указан `xiaomi-research/Xiaomi-OCR-0`. При первом использовании Transformers загрузит модель по этому ID в собственный кэш. Вместо ID можно задать в `XIAOMI_OCR_MODEL_PATH` абсолютный путь к локальной папке модели или путь от папки скилла с префиксом `./`, например `./.cache/model`. Нужна исходная модель в формате Transformers/Safetensors; GGUF не поддерживается. Переменные окружения процесса имеют приоритет над `.env`. Для работы без сети все файлы модели и зависимости должны быть доступны заранее.

В папку скилла должна быть разрешена запись: здесь находятся журнал и архив, а также может размещаться локальный кэш модели. Проверка после установки описана в [test/README.md](test/README.md).

## Использование

Для OpenClaw в Windows используйте команду из [SKILL.md](SKILL.md) с именем агента и ID сессии. Для самостоятельного запуска или другого агента передайте `-s`, чтобы отключить уведомления; `--stdout` дополнительно выводит текст. Запускайте скрипт через Python виртуального окружения, указывайте абсолютные пути к входным файлам и ставьте флаги перед ними. Например, из папки скилла в PowerShell:

```powershell
& .\.venv\Scripts\python.exe .\ocr.py -s --stdout 'C:\path\to\image.jpg'
```

Поддерживаются PDF, JPG, JPEG, PNG, WEBP, BMP, TIF и TIFF. Скрипт перемещает каждый входной файл в `data/archive` и сохраняет рядом `.txt` с тем же именем. Одноимённый входной файл заменяется, если не указан `-p` / `--protected`. Используйте копию, если исходник должен остаться на месте. `-k` оставляет входной файл и расшифровку на месте для отладки.

Существующая расшифровка удаляется перед распознаванием независимо от `-p`. При ошибке до записи она будет отсутствовать, а ошибка записи может оставить неполный файл. Для архива нужны права на чтение и запись, а для перемещения входного файла — право удаления в исходной папке. Сообщения записываются в `logger.log`, ошибки также выводятся в stderr. Нативные библиотеки могут писать непосредственно в stdout.

Выбранная модель не готова для надёжного распознавания русских текстов; сверяйте результат с оригиналом. Если результат содержит `Xiaomi OCR returned unknown response`, изображение не распознано.
