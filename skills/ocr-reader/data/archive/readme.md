# OCR archive / Архив OCR

Processed images, PDFs and transcripts are stored here. The skill needs read and write access to this directory and permission to delete source files from their original locations when moving them.

Здесь хранятся обработанные изображения и PDF вместе с распознанным текстом. Для работы скиллу нужны разрешения на просмотр (чтение) и запись в эту папку; для перемещения исходных файлов также нужно разрешение на их удаление в исходной папке.
