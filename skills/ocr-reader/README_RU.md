# OCR reader

[English](README.md)

Распознавание текста на изображениях и в многостраничных PDF с помощью docTR. Перед распознаванием изображения выпрямляются через docuwarp. Основная интеграция рассчитана на Windows и OpenClaw. Для других агентов и операционных систем используйте `-s`, чтобы отключить уведомления; на целевой системе должны быть установлены совместимые зависимости Python. Реальный запуск OCR проверен на Windows; другие ОС пока не проверялись.

## Установка

Поместите папку `ocr-reader` туда, где ваш агент ищет скиллы. Внутри неё создайте окружение Python 3.11+ и установите зависимости:

```powershell
python -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

В Linux и macOS используйте `.venv/bin/python`. При первом запуске могут загружаться веса моделей. В папку скилла должна быть разрешена запись: здесь находятся лог, кэш и архив.

## Использование

Для OpenClaw в Windows используйте команду из [SKILL.md](SKILL.md) с именем агента и ID сессии. Для самостоятельного запуска или другого агента передайте `-s`; флаг `--stdout` дополнительно выводит текст. Полная инструкция проверки после установки находится в [test/README.md](test/README.md).

Скрипт перемещает входной файл в `data/archive` и сохраняет рядом текст. Существующий одноимённый файл заменяется, если не указан `-p` / `--protected`. Используйте копию, если исходник должен остаться на месте. Флаг `-k` предназначен для отладки.

Пути `DOCTR_CACHE_DIR` и необязательный `OCR_UNWARP_MODEL_PATH` задаются в `.env` или окружении процесса; окружение имеет приоритет. Путь к кэшу может быть абсолютным или относительным к папке скилла; путь к модели выпрямления указывайте абсолютный. Переменные вида `${MODELS_DIR}` в путях не раскрываются.

Модель распознавания по умолчанию в docTR 1.1.0 не поддерживает кириллицу и не готова для русских текстов. Поддержка языков зависит от модели и версии библиотеки.
